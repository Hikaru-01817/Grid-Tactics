# Grid Tactics Ver.1.0

`Grid Tactics` は、前列・後列に分かれた6マス盤面で戦う1人用デジタルカードゲームです。HTML/CSS/JavaScriptだけで動作し、`index.html` をブラウザで開くだけで遊べます。

Ver.1.0でWeb版制作はいったん完成です。今後は必要に応じて、Unity版など別環境への移行を想定しています。

## 起動方法

```text
card-game/index.html
```

上記ファイルをブラウザで開いてください。外部ライブラリやサーバーは不要です。

## 基本ルール

- 相手プレイヤーのHPを0以下にすると勝利します。
- 自分のHPが0以下になる、またはデッキが0枚の状態でドローしようとすると敗北します。
- 各プレイヤーは前列3マス、後列3マスの合計6マスにユニットを配置します。
- ユニットは召喚したターンには基本的に攻撃できません。
- 攻撃可能なユニットを選び、攻撃対象を選択します。

## 前列/後列

- 相手の前列がすべて埋まっている場合、相手プレイヤーへ直接攻撃できません。
- 後列ユニットの前に同じ列の前列ユニットがいる場合、その後列ユニットは攻撃対象になりません。
- 守護、疾走、突進などのキーワード能力はカード定義に従って処理されます。

## デッキ構築

- 使用クラスは `knight` と `mage` の2種類です。
- `neutral` は独立した使用クラスではなく、ナイト/メイジ両方のデッキに入れられる共通カードです。
- 通常デッキは30枚ちょうどで保存できます。
- エクストラデッキは5枚ちょうどで保存できます。
- レアリティごとの同名カード上限は以下です。

```text
bronze / silver: 3枚
gold: 2枚
legend: 1枚
```

## エクストラデッキ

エクストラカードは通常デッキには入らず、条件を満たすと対戦中にエクストラエリアから使用できます。

- `extra_unit` と `extra_spell` のみエクストラデッキに追加できます。
- 選択クラス + `neutral` のエクストラカードだけを採用できます。
- 同名カードは1枚までです。

## 覚醒

覚醒ポイントを1消費して自分のユニット1体を強化します。Ver.1.0では攻撃力と体力が上昇し、一部カードは覚醒時効果を持ちます。

## 操作方法

- カードをクリックして使用します。
- ユニットは空きマスを選んで召喚します。
- 攻撃可能なユニットを選び、攻撃対象を選択します。
- 条件を満たすとエクストラカードを使用できます。
- 覚醒ボタンを押してからユニットを選ぶと覚醒できます。
- 対戦画面右上の3本線メニューから、ホーム、デッキ編集、カード一覧、遊び方、再戦、リタイアを選べます。

## fullImage方式

`fullImage` は単なるイラストではなく、カード枠、イラスト、カード名、種族、効果文、キーワード、条件テキストまで含む完成カード画像です。

`fullImage` があるカードでは、Web側でカード名・種族・効果文・キーワードを再描画しません。Web側で重ねるのはコスト、攻撃力、体力などの数値と、選択中・使用不可・攻撃可能などの状態表示だけです。

`fullImage` がないカードだけ、Web側でダミーカード表示を生成します。

## NUMBER_LAYOUT_BY_NAME

完成カード画像上の丸枠に数値を合わせるため、`cards-v02.js` の `NUMBER_LAYOUT_BY_NAME` でカード名ごとに座標を調整できます。

```js
"鋼の守護者": {
  cost: { x: 16.8, y: 10.5 },
  attack: { x: 17.0, y: 91.2 },
  hp: { x: 84.5, y: 91.2 }
}
```

座標はカード画像内の中心位置をパーセントで指定します。未指定の場合は `DEFAULT_NUMBER_LAYOUT` を使用します。
